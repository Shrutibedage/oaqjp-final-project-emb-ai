# Final Project

## Emotion Detector

This Final Project implements an Emotion Detector application that analyzes text and identifies five emotions: anger, disgust, fear, joy, and sadness.

### Technologies Used
- Python
- Flask
- Watson NLP Emotion Detection API
- HTML and CSS
- Unit testing with Python's `unittest`
- Pylint for static code analysis

### Project Structure
- EmotionDetection/ — Emotion detection package
- server.py — Flask web application
- templates/index.html — User interface
- tests/test_emotion_detection.py — Unit tests
- requirements.txt — Project dependencies
